### Character Sprites 01

This is a set of 10 sprites of one blonde-haired girl character, made for visual novels. It contains many display of emotions: neutral, sad, angry, blushing, closed eyes. 

My assets are all drew by hand, by me (iam4cher), and does NOT contains any Generative AI. 

The dimensions are either:
-2400x3000
-880x1100

You are free to use my characters for any project of yours, commercial use included (meaning that you can sell a game that uses my assets).

However, you must not resell those assets (= meaning selling a asset pack with my characters, as if you're the one who drew them). 

You can freely edit those assets to your liking: changing the colors, adding more emotions, redrawing the character as you like. 

If you need more options, that you need more outfits, expressions, or to modify some aspects of the character, you can DM me and I'll do it for free (as long as it isn't too much work).
